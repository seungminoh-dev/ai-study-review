지금 상태

1. 스파이크 토큰

배포할 때 만든 SPIKE_TOKEN을 넣어요. 이 기기 안에만 저장돼요. 홈 화면 앱은 Safari와 저장소가 따로라서 한 번 더 넣어야 해요.

2. 웹 푸시 (확인 항목 5)

  1. iPhone은 Safari 공유 버튼 → 홈 화면에 추가 → 홈 화면 아이콘으로 다시 열어요.
  2. 홈 화면 앱에서 토큰을 넣고 "알림 켜기"를 눌러요.
  3. "1분 뒤"나 시각 예약을 누르고 앱을 닫아요. 알림이 오면 아래 표에서 지연을 봐요.

3. 쿠키 (확인 항목 7)

  1. Safari에서 "쿠키 심기"를 눌러요.
  2. 홈 화면에 추가한 뒤, 홈 화면 앱에서 "쿠키 확인"을 눌러요.
  3. "있음"이면 Safari 로그인이 홈 화면 앱으로 이어진다는 뜻이에요.
