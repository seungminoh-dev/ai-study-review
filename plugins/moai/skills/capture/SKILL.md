# 모아이에 저장

모아이 MCP 서버의 `find_concepts`, `save_learning` 도구를 쓴다 (도구 이름이 그렇게 끝난다). 도구가 보이지 않으면 플러그인 README의 연결 방법을 알려 주고 멈춘다.

1. 먼저 세 줄로 정리해 보여 준다: 막혔던 지점 / 새로 확보한 핵심 용어 / 다음에 다시 볼 질문.
2. 이번 대화의 개념 이름들을 쉼표로 이어 `find_concepts`를 부른다. 같은 개념이 있으면 그 key를 쓴다.
3. 저장할 개념 이름과 카드 문제 목록을 짧게 보여 주고, 사용자가 좋다고 하면 저장한다.
4. `save_learning`을 부른다. `source`는 `"claude-code"`로 한다. 나머지 규칙(판정, 카드 단계, 연결)은 도구 설명을 따른다.
   - 판정은 사용자가 직접 설명하거나 답한 부분이 있을 때만 넣고, `said`에는 사용자 원문을 그대로 넣는다.
   - 코드 예시는 카드의 `code`에 넣는다.
   - **비밀값은 어느 칸에도 넣지 않는다** (`said`, `code`, `prompt`, `explain`, `final_answer` 모두). 토큰, API 키, 비밀번호, 접속 URL, `.env` 값, 사내 주소처럼 보이는 것은 `<비밀값>`으로 바꾸고, 사용자 원문이라도 그 부분은 지운다.
5. 검사에 걸리면 고칠 점을 반영해 다시 부른다. 저장 결과를 한 줄로 알린다.

공부와 상관없는 대화(일반 코딩 작업 등)는 사용자가 원해도 먼저 무엇을 저장할지 확인한다.
